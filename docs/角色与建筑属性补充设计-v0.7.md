## 1. 文档定位与数值来源

本文件独立记录玩家、普通敌军、BOSS、已完成建筑和施工工地的属性，作为主策划案的补充设计。主案负责玩法流程，本文件集中提供属性口径、完整成长表和战斗参数。

- **沿用：** 主案已有的生命、攻击、护甲、移速、攻击间隔、建筑费用、等级成长和技能核心效果。
- **计算展开：** 按主案公式计算的12级玩家表、20条建筑等级属性和敌军波次倍率示例，不另行调平衡。
- **新增建议：** 主案未确定的碰撞半径、攻击前摇、弹道参数、BOSS技能施放距离及首次冷却等，均在对应表格或段落中明确标注。
- 本文件不代表已经通过实机平衡测试，也不自动把上一份检查报告的所有修正建议写入主案。涉及免费重建、拆除、出生点失效、普通受击保护分组等，仍待另行决定。
- 主案已有数值与本表发生意外差异时，以主案为核对来源；本文件标为新增建议的项目，是后续实现的明确候选值。修复分母等主案存在歧义的项目，本文件单列建议口径，不静默覆盖。

## 2. 通用属性口径

### 2.1 单位与精度

| 字段 | 单位/类型 | 含义 |
|---|---|---|
| 最大生命、当前生命 | 数值 | 当前生命≤当前有效最大生命；生命归零后不能继续作业或攻击 |
| 攻击力 | 伤害/次 | 护甲减伤前的基础伤害，独立于攻击间隔 |
| 护甲 | 数值 | 物理伤害减免参数，不是百分比 |
| 移速 | 格/秒 | 场景世界距离；动画速度不能替代逻辑位移速度 |
| 攻击间隔 | 秒/次 | 连续两次攻击起手之间的最短时间，包含前摇 |
| 普攻频率 | 次/秒 | 1÷攻击间隔，0攻击建筑记为“—” |
| 普攻DPS | 伤害/秒 | 攻击力÷攻击间隔；不计护甲、技能、失误、光环和暴击 |
| 普攻射程 | 格 | 按攻击者与目标碰撞轮廓的最短距离判断，沿用主案边缘距离口径 |
| 技能施放距离 | 格 | 本补充建议统一按施法者中心到目标中心计算，区别于普攻射程 |
| 范围技能半径 | 格 | 圆心到目标中心的距离；建筑使用格中心 |
| 工作量W | 工作量单位 | 基础建造效率1时，W等于新建所需秒数 |
| 效率 | 工作量/秒 | 使用同一W标尺；基础修复效率为基础建造效率的50% |
| 建造点费用 | 资源 | 新建/升级费用为整数，修复允许小数 |

内部保留浮点精度，属性面板生命与伤害可四舍五入，间隔显示2～3位小数；不得每帧把生命、修复费用或BUFF换算结果截成整数。表中的DPS只是单目标、持续命中条件下的横向比较值，不用于直接判断实战强度。

### 2.2 基础、成长与临时修正

属性分为三层：类型基础值 → 建筑等级/敌人出生波次成长值 → 玩家BUFF、装备和控制效果修正后的有效值。

普通敌人的波次倍率建议在出生时根据其所属波次固定。第10波出生的敌人存活到第11波，不再次乘第11波倍率；延迟生成的第10波单位仍使用第10波属性。新波始终按战斗时间触发，不依赖上一波清场。

加入佣工的个人属性使用当前队伍等级对应的移速与作业效率，生命以100/100开始；等级、经验和建造点继续引用共享值，不因加入额外发放。新佣工出生点从队伍中心向外寻找最近的合法平地，必须避开现有佣工、地面障碍、建筑和敌人碰撞体。

### 4.2 行为与碰撞参数

除弓箭手已有的0.5秒瞄准、8格/秒弹速与全部敌人的逐逻辑帧索敌检查外，下表为新增建议。

| 类型 | 圆形碰撞半径 | 攻击前摇 | 起手后至下次可起手的剩余时间 | 普攻形式 | 备注 |
|---|---:|---:|---:|---|---|
| 步兵 | 0.25格 | 0.30秒 | 0.90秒 | 近战单体 | 主体数量压力 |
| 重装兵 | 0.38格 | 0.55秒 | 1.05秒 | 近战单体 | 动作更慢，给玩家读招空间 |
| 弓箭手 | 0.25格 | 0.50秒 | 1.30秒 | 直线箭矢单体 | 发射时锁定目标位置，不追踪 |
| 骑兵 | 0.32格 | 0.35秒 | 1.05秒 | 近战单体 | 首版无额外冲锋技能 |
| 飞翼掠夺者 | 0.28格 | 0.40秒 | 1.10秒 | 近战单体 | 悬空移动，无视地面障碍与泥泞减速 |

“剩余时间”不是必须站立的后摇：建议伤害/发射后允许恢复移动，攻击周期仍计时。敌人进入技能控制、失去目标时不清零已消耗的攻击周期。

同一高度层的怪物采用表内半径的圆形硬碰撞，两个圆的中心距离不能小于半径之和。地面怪物与建筑/工地采用圆形对1×1格方形的碰撞检测，移动和出生均不得重叠；拥挤时通过相互推挤和排队前进，不造成额外伤害。空军只和空军碰撞，可与地面单位或建筑共享水平坐标。大体型BOSS的普通与破障寻路都必须按自身半径计算。

飞翼掠夺者只受地图外边界约束，直线越过高地边缘、石头、河流、泥泞和建筑，不参与破障。它保留逐逻辑帧索敌与嘲讽＞玩家＞建筑的攻击优先级；自身攻击不受石头视线阻挡，防御塔对它的攻击规则不变。空军不会推动地面玩家。

**普通攻击补充建议：**

- 出生后普通攻击就绪，但只有取得合法目标并完成前摇才造成伤害。
- 近战起手时锁定目标；伤害帧重新检查目标存活、可受击、边缘距离和地形视线。条件失效则挥空，仍消耗完整攻击周期，不在同次攻击中改打建筑。
- 箭矢发射前检查合法目标与石头视线，锁定发射时的位置；之后沿固定直线移动。建议箭矢碰撞半径0.06格，不穿透，最大飞行距离10格，碰到石头或首个可受伤敌对实体后消失。
- 弓箭手箭矢的敌对实体为玩家、己方防御建筑和工地；其他怪物不挡箭。建筑被直接命中与“建筑不作为地形视线障碍”分开处理。这是补充的弹道命中建议，尚未写回主案。
- 装备无敌玩家不作为箭矢命中对象，箭继续沿原方向移动；普通受击保护中的玩家仍可拦下箭，但不扣生命。
- 玩家站在建筑格时，若敌方箭矢同时相交玩家与建筑，优先结算本次攻击选定的目标；无法命中原目标时才检查其他敌对实体，避免建筑替代玩家永久挡箭。
- 索敌每个逻辑帧检查一次（当前30次/秒）。生成时在存活且可索敌的佣工中选择最近者；攻击范围内有多名佣工时锁定最近者。范围内出现玩家这一更高优先级目标时立即从建筑切换；前摇期间换目标会重新完成前摇且不缩短攻击周期。已发射弹道及已锁定技能落点保持不变。无敌无目标时站立。

**修复上限口径建议：** 本文件选择当前有效最大生命H（含等级与坚基BUFF）作为修复计算依据，以保持按生命比例维修；这补齐主案“当前等级最大生命”的歧义，但原案未改。

| 共鸣BUFF | 建筑周期技能冷却 | 每层缩短15%，总缩短不超过50% |
| 猎骑/攻坚BUFF | 攻击对目标标签的增伤 | 分别+35%、+25%，同目标同时符合时相加 |
| 余势BUFF | 单体普攻击杀后的额外伤害事件 | 正溢出量×50%×层数，比例最高100%，不递归 |

所有被动BUFF默认作用于玩家5格光环内已完成建筑。主动装备最多携带2件，BUFF不占格；不能把未携带主动装备的效果计入属性面板。

## 8. 程序配置建议

| 配置 | 主键 | 建议字段 |
|---|---|---|
| 玩家基础 | player_worker | 玩家编号、生命、护甲、碰撞半径、受击保护时间、位置、输入、作业任务 |
| 队伍配置 | party_size | 共享等级/经验/建造点/装备/BUFF、波次间隔、敌军数量倍率 |
| 玩家等级 | level | 累计经验、移速、基础建造/修复效率、建筑上限、解锁项 |
| 普通敌军 | enemy_id | 基础生命/攻击/护甲/移速、周期/前摇/射程、半径、标签、弹道ID、奖励 |
| BOSS基础 | boss_id | 固定战斗属性、半径、标签、普攻属性、技能列表、低血量阶段属性 |
| 建筑基础 | building_id | 占地、解锁等级、新建费用、W、初始工地生命/护甲、普攻模式 |
| 建筑等级 | building_id + level | 生命、护甲、攻击、升级费用、技能参数 |
| 技能 | skill_id | 施放距离算法、距离、视线要求、准备/预警、范围、伤害、控制、周期、首次等待 |
| 弹道 | projectile_id | 直线/追踪/固定落点、速度/飞行时间、碰撞半径、目标过滤、寿命、穿透规则 |

不同时把“攻击间隔”和“攻速次数”配置为两个独立可编辑真值；保留基础攻击间隔，实时推导有效频率和前摇。普通敌人出生时记录spawn_wave，建筑记录building_level，不能混用当前全局波次和玩家等级。

## 9. 核对与使用范围

本版静态核对范围：12条玩家等级、5类普通敌人及波次示例、4名BOSS核心属性、5类建筑×4级共20条属性、5类工地、周期技能等级伤害。

优先实测新增建议：玩家站塔内的命中顺序、各体型能否通过地图通道、近战离开范围后挥空、远程攻击绕石头的表现、多个BOSS技能并存、光环进出与修复费用。

本文件新增1类普通空军，没有增加新的玩家角色或建筑类型，也没有改动20波定时刷新、主动双格与被动BUFF的结构。防线死局、主动拆除、出生点重选及受击保护是否隔离BOSS伤害仍保留为主案待定事项。

## 1. 游戏定位与核心体验

玩家是一名被敌军追击的建筑工人，依靠选择施工位置、组织火力与控制、利用地形和不断转移来生存。主角不承担常规输出，建筑自动战斗。

玩家持续处理三个问题：

1. **在哪里站住？** 地形和已有火力决定安全施工窗口。
2. **这几秒做什么？** 新建扩大覆盖，升级提升现有战力，修复保住关键建筑。
3. **什么时候撤？** 施工进度能够保存，但未完工建筑可能被摧毁。

核心循环：观察来敌 → 引入火力区 → 找到短暂安全位置 → 施工/升级/修复 → 移动躲避 → 获得建造点与经验 → 扩展或重组防线。

希望玩家逐渐从“躲在第一座塔附近”成长为“带着敌群在多个阵地之间转移”。允许稳守一个阵地，但远程压制、骑兵包抄和BOSS范围攻击会推动玩家调整站位。

## 2. 单局流程与胜负

### 2.1 开局

- 玩家出生于地图中心附近的平地；右侧相邻格放置一座已完成的1级箭塔。
- 玩家初始生命100，移动速度3.2格/秒，等级1，建造点120。
- 玩家拥有2个主动装备格，初始均为空；仅可携带主动装备，没有额外备用背包。被动BUFF独立挂在玩家身上，初始为空，不占装备格。
- 开局提供10秒准备时间，不计入战斗计时。准备期间可移动、施工；倒计时结束启动第1波。
- 初始解锁箭塔、拒马；初始建筑上限6座，起始箭塔计入上限。
- 首次教学提示原地建造、移动中断及靠近建筑修复。提示不暂停敌人之外的规则；首次说明可在准备阶段展示。

### 2.2 胜利与失败

- 玩家生命归零立即失败。单局不提供复活。
- 第20波最终BOSS死亡，且全部20波的敌人均已生成并被消灭后胜利。
- 14分15秒开始第20波；理想情况下15分钟左右清场。15分钟是节奏目标，不是自动胜利时间。
- 清场超时继续战斗并计时，不无限增加额外波次。这样不会出现只靠跑步拖到15分钟获胜的策略。
- 所有建筑被毁不会立即失败；未花费资源仍可使用，但资源不足且无输出时可能陷入无法翻盘的状态。
- 暂停菜单提供“重新开始”和“结束本局”，允许玩家主动重开。

### 2.3 结算

显示生存时间、达到波次、击杀数、最终等级、建造/损失建筑数、总修复量、建造点收入与支出、各类建筑伤害、最终携带的主动装备、主动使用次数及已获得的被动BUFF。首版没有局外永久属性成长，装备、BUFF与地面掉落仅保留至本局结束。

## 3. 地图与空间规则

### 3.1 地图规格

- 建议采用64 × 64格方形地图、俯视角、镜头跟随玩家。常规视野约覆盖24 × 14格，可随窗口比例调整。
- 第一版使用一张手工验证的固定地图；随机地图放在核心战斗成立后制作。
- 中心7 × 7格为平地安全起点，中心区不放置河流或大型石群。
- 中心区外围布置断续石脊、水洼、短支流与泥地带，形成环状但不封闭的战斗分区。相邻障碍之间保留多条可替代路线，避免单一路口决定整局。
- 地图包含4块高地平台，共574格，分布在中心阵地四周；每块高地至少设置2处双格坡道。高地平台缩小开阔区域，并形成可守的绕行口。
- 高地边缘占用完整地形格，以顶部亮沿、崖壁渐暗面和底部阴影表现落差；这些断崖格不可站立或建造。坡道使用连续色阶和顺坡引导线表现斜面，不再绘制成横纹楼梯或单纯的边界线。
- 石群构成局部掩体；河流和水洼构成绕行障碍，不形成无法抵达的独立出生区。
- 河流可以由岸间的平地通道连接，通道至少3格宽；该通道仍使用平地规则，无需新增桥梁地形。
- 供大型BOSS使用的主要通道至少3格宽；不能只验证普通单位或格中心可达。

| 地形 | 玩家通行 | 敌人通行 | 建造 | 远程攻击 |
|---|---|---|---|---|
| 平地 | 可以 | 可以 | 可以 | 不阻挡 |
| 石头 | 不可以 | 不可以 | 不可以 | 阻挡直射箭矢和视线；允许迫击炮抛射越过 |
| 河流 | 不可以 | 不可以 | 不可以 | 不阻挡远程射击，可隔河对射 |
| 泥泞地 | 可以；移动速度×70% | 可以；移动速度×70% | 不可以 | 不阻挡，可正常射击 |
| 高地平面 | 可以 | 可以 | 平地部分可以 | 不额外阻挡射击 |
| 高地边缘 | 不可以跨越 | 地面敌军不可以跨越 | 不可以 | 不额外阻挡射击 |
| 坡道 | 可以切换高低地 | 地面敌军可以切换高低地 | 可以 | 不阻挡 |

地图边界不可通行。生成地图时要求所有出生点与中心区域在不考虑建筑的情况下连通，全部可站立地形通过坡道属于同一可达区域。寻路将泥泞地计入额外移动成本：存在合理平地绕路时优先绕行，绕路过远时允许穿越泥地。空军只受地图边界限制，无视地形移动成本和高度切换限制。

### 3.2 建筑占位

- 每座建筑占1格，同格不能叠放建筑。
- **玩家可进入己方建筑格；敌人不能穿过建筑格。** 这是支持“玩家在当前位置建造、升级、维修”的基础抽象。
- 角色与建筑视觉分层显示，玩家站在塔上时采用半透明塔体或角色轮廓，避免遮挡。
- 玩家处于建筑格时仍可受伤。敌人攻击玩家只检查距离、地形视线与技能限制，己方建筑不会为站在格内的玩家提供绝对免疫。
- 建筑不阻挡直射弹道；石头才提供明确的射线遮挡。这样避免敌人无法攻击站在塔里的玩家。
- 玩家允许用建筑封路。敌人无可行路线时会攻击阻路建筑，不允许靠封路令敌人永久停机。
- 工地建立后即占格、具有碰撞和可被攻击的实体；因此需要实现敌人的破障路径。

### 3.3 出生规则

- 优先选择当前镜头外、距离玩家至少14格的已验证出生点。
- 距地图边缘太近、没有合格屏外点时，选距离玩家至少10格的合法点，并以边缘箭头提前预警2秒；不能在玩家脚下生成。
- 地面敌军出生点必须位于可站立地形、无建筑占用，并与玩家所在区域存在含坡道的地形通路。空军出生点允许位于任意非边界空域，不受地面建筑占用影响。
- 普通波分2～3批进入，间隔4～6秒。波次倒计时与批次倒计时分别管理。

## 4. 玩家与操作

### 4.1 基础属性

| 属性 | 初始值 | 说明 |
|---|---:|---|
| 最大生命 | 100 | 无常驻自动回血 |
| 移动速度 | 3.2格/秒 | 等级成长；移动不消耗资源 |
| 护甲 | 0 | 首版不设计主角护甲成长 |
| 基础建造效率 | 1.0 | 决定每秒完成的施工工作量，装备倍率另算 |
| 基础修复效率 | 基础建造效率 | 与建造使用同一套工作量单位，装备倍率另算 |
| 初始建造点 | 120 | 击杀自动获得 |
| 基础攻击 | 无 | 用“无主动攻击”落实几乎没有攻击能力，首版避免额外武器系统 |

玩家承受一次普通伤害后有0.3秒普通受击无敌时间，避免大量敌人同帧接触造成瞬间死亡。此规则对所有敌方伤害统一生效，持续区域伤害按各次判定检查；敌人不会因伤害被免疫而返还攻击冷却。

普通受击保护只免疫伤害，不移除玩家的索敌资格。第4.3节的装备无敌另有“不可索敌”效果，两者必须分开实现。

升级时回复10点生命，不超过最大生命。BOSS死亡不额外全恢复。

### 4.2 推荐PC操作

| 操作 | 输入 | 规则 |
|---|---|---|
| 移动 | WASD / 方向键 | 有效位移会停止当前作业 |
| 选择建筑 | 数字1～5或底部按钮 | 仅选择类型，不消耗资源 |
| 开始/继续建造 | E | 在玩家脚下格确认工地；静止持续施工 |
| 修复 | R | 玩家位于受损的已完成建筑格，按一次开始持续修复 |
| 升级 | F | 玩家位于已完成建筑格，满足条件后瞬间升级 |
| 使用主动装备格1/2 | Q / 空格 | 触发对应主动装备 |
| 拾取地面道具 | G | 玩家到达道具格；主动装备按空格/替换规则处理，BUFF道具直接转为身上BUFF |
| 取消当前作业 | Esc | 首次退出作业；无作业时打开暂停菜单 |
| 暂停 | P | 暂停模拟与所有战斗计时 |

- 不需要持续按住施工键；移动、主动取消、目标毁坏、完成作业会退出作业状态。
- 仅按下移动键但被石头阻挡、没有产生位移时，不中断施工。
- 玩家一次只能施工或修复一个目标。按R开始修复会替换当前作业。
- 玩家必须位于目标格才能继续工地、修复或升级；不能隔空操作，也不允许鼠标远距离下塔。
- 打开建筑信息面板不暂停战斗，暂停菜单会暂停。

### 4.3 双主动装备与被动BUFF系统

#### 4.3.1 携带与效果类型

- 玩家只能携带2件主动装备，两个槽位均仅接受主动装备；被动效果通过拾取BUFF道具获得，不再作为可穿戴装备。
- 首版每件主动装备或BUFF道具只提供一种效果，不增加品质、强化和词条随机值。以下名称、数值和冷却均为建议初值。
- 主动装备由玩家手动使用，瞬间生效，不打断当前施工或修复，不消耗建造点。
- BUFF道具拾取成功后，移除地面实体并将被动BUFF附加到玩家身上，立即生效，不需要确认穿戴；即使两个主动格已满也可以拾取。
- 被动BUFF不占携带容量、不参与替换、不能卸下或重新丢回地面。持续时间暂定为本局剩余时间，本局结束清除；此持续方式为补充建议。
- 初版允许同名主动装备同时携带，同名主动共享使用冷却，避免双无敌交替实现过长的安全期。被动BUFF可同时持有多种，不设置“两种”上限；重复拾取同类BUFF的建议叠加规则见第4.3.5节。
- 未拾取的地面主动装备和BUFF道具均不提供效果。

主动效果的持续时间从按键成功触发起计算，移动或停止作业不暂停倒计时。不同主动可同时生效，各自独立计时；重复按键不刷新持续时间。冷却从成功使用时开始计时。

瞬时装备只结算一次；护盾、警报、泡沫和超载等效果的附着位置与结束条件见第4.3.7节。使用条件不满足时不触发、不扣费、不进入冷却，并提示原因。

主动装备第一次由BOSS生成时处于就绪状态。冷却既记录在具体装备实例上，也记录在角色的同类主动效果上，只有两者均就绪才可使用。落地、拾回或换槽不重置冷却；冷却在地面继续随战斗时间流逝。卸下正在生效的主动装备会立即终止该装备效果，剩余冷却保留。暂停时效果与冷却都暂停。

#### 4.3.3 建造、修复加速的计算

设B为角色等级决定的基础建造效率，C为建造装备倍率，R为修复装备倍率；未激活时C=1、R=1，激活对应装备时变为2。

- 当前建造效率 = B × C。
- 当前修复效率 = B × R。
- 疾建手套不会连带提高修复速度，抢修扳手不会提高建造速度；建造与修复在无装备临时加成时具有相同基础效率。
- 加速只改变每秒完成量，不改变已经完成的工作量、不降低资源费用，也不影响瞬时升级。
- 效果中途结束时，剩余工程按恢复后的速度继续，不重置或折算已完成进度。

例：1级角色建箭塔原需3秒，疾建手套生效期间完成同样工作只需1.5秒；箭塔从近空血修满原需约3秒，抢修扳手生效期间约需1.5秒，修复费用相同。

#### 4.3.4 装备无敌与敌军停留

- 无敌持续期间玩家不受敌方伤害、击退或敌方控制，并从普通敌人和BOSS的目标候选中移除；玩家可以正常移动、建造、修复、升级、拾取和使用另一件装备。
- 无敌不是穿墙：石头、河流与建筑原有通行规则不变。为避免拥挤推挤中断无敌施工，玩家与敌人的软推挤在该效果期间关闭。
- **“范围内”本版暂按敌人自身攻击范围解释**，仍需满足地形视线条件；不额外扩大索敌半径。若后续希望怪物主动接近附近建筑，再单独配置警戒范围。
- 玩家进入装备无敌时敌人立即重新决策：保留有效嘲讽的优先权；否则攻击自己攻击范围内的合法建筑/工地；没有合法目标则原地站立，继续定期检查。
- 无目标敌人不追踪玩家最后位置，不向远处建筑移动，也不为接近无敌玩家进行破障。有效嘲讽仍可使敌人向嘲讽塔移动、攻击或破障。
- 即使被范围外的防御塔射击，敌人也不会因此增加反击追击逻辑；无有效嘲讽且攻击范围内没有目标时，仍站立不动。此停留是用户指定的装备效果，不是寻路故障。
- 新建工地出现在站立敌人的攻击范围内后，敌人可立即转为攻击工地。无敌保护玩家，不保护玩家正在操作的建筑。
- 无敌结束或因替换装备提前终止时，敌人立即重新检查玩家资格并恢复第7.1节常规决策，不等待下一波。
- 尚未命中的、以玩家为目标的普通攻击前摇取消，已经消耗的攻击冷却不返还；已发射箭矢和已生成范围伤害继续存在，但不能伤害无敌玩家。
- BOSS尚在预警、以玩家为目标的技能在玩家进入装备无敌时取消并正常进入冷却；已经落地的箭雨、已启动的冲锋等继续执行原来的区域/方向，不重新锁定玩家，也不伤害或击退无敌玩家。冲锋不因接触无敌玩家而停止，仍会撞击建筑或地形。
- BOSS在玩家不可索敌时不能新启动依赖玩家目标的技能，技能就绪状态保留；普攻仍可攻击范围内建筑。无敌结束后重新预警再施放，不能省略前摇。

#### 4.3.5 玩家被动BUFF、光环与属性叠加

- 光环以玩家实时位置为中心，用玩家中心到建筑格中心的距离判断，距离≤5格生效；覆盖所有已完成己方防御建筑，不覆盖工地。
- 光环随玩家移动，不检查石头、河流或建筑遮挡；装备无敌不会使光环失效。
- BUFF挂在玩家身上，范围内建筑获得对应属性加成，建筑离开覆盖范围后失去加成，但玩家身上的BUFF不会消失。主动装备替换不影响已获得BUFF。
- 不同被动BUFF同时生效；同类重复拾取暂定增加1层、每层数值相加，不叠乘、不刷新出新的短时倒计时。首版去重掉落池不会产生同类重复，叠层作为扩展规则保留。
- 攻击力按建筑当前等级、未受BUFF加成的数值计算：最终攻击力 = 等级攻击力 ×（1 + 所有生效攻击加成之和）。两层火力祝福为+50%，不是相乘至+56.25%。
- 最终护甲 = 等级护甲 + 所有生效护甲加成；拒马和嘲讽塔可获得护甲加成，0攻击的建筑不会因百分比加成产生攻击。
- 普攻间隔 = 基础攻击间隔 ÷（1 + 所有生效攻速加成之和）。一层速射祝福使箭塔0.8秒间隔变为约0.667秒，两层变为约0.571秒；一层速射祝福与超载发电机同时生效时为0.8÷1.8≈0.444秒。
- 攻速不缩短周期技能冷却、弹道飞行时间或控制持续时间；技能冷却仅由共鸣祝福等明确效果改变。技能伤害引用攻击力时可受攻击光环加成。
- 进出光环范围或获得/叠加BUFF时重新计算属性，保留普攻周期已完成的比例，不额外获得一次普攻；单纯替换主动装备不改变光环属性。
- 攻击伤害在发射时确定，目标护甲在命中时读取，防止弹道因玩家移动而反复改变攻击值。

#### 4.3.6 拾取、替换与地面保存

- BOSS掉落的主动装备或BUFF道具出现在死亡位置对应的合法地图格，不自动入账。玩家必须到该格主动按G拾取；建造点和经验仍自动入账。
- 先检查道具类型：BUFF道具直接转为玩家被动BUFF并移除地面实体，不检查主动格容量、不打开替换界面、不产生旧道具落地；该转化只结算一次。
- 主动装备有空格时，拾取后进入编号较小的空格并立即穿戴；地面实体移除。
- 仅当拾取主动装备且两格已满时，展示新主动装备与两件已携带主动装备，点击要替换的槽确认。选择界面不暂停战斗；取消或离开道具格则关闭，装备保持原状。
- 替换成功后，新装备穿入选中槽，旧装备落在**玩家当前所在地图格**。此处“格子所在位置”指地图格，不是背包UI位置。
- 替换按一次事务完成：重新检查玩家仍在道具格 → 移除待拾取地面装备 → 确定旧装备落点 → 交换穿戴/地面状态。不能先删除旧装备再尝试找位置。
- 每个地图格最多显示1件地面道具，主动装备与BUFF道具共用这一占位规则。拾取释放的本格可以立即放置旧主动装备，因此常见替换结果是两件主动装备原地交换。
- 目标格已有其他道具时，按距离由近到远搜索周围格，逐圈扩展；同一圈按上、右上、右、右下、下、左下、左、左上的顺时针方向顺延，后续圈按相同顺时针顺序遍历。
- 合法落点须在地图内、为玩家可到达的平地、且没有其他地面道具；跳过石头、河流及不可达孤岛。建筑或工地所在平地允许落装备，因为玩家可进入己方建筑格。
- 道具本身不参与碰撞，不阻挡玩家、怪物、弹道、寻路或施工，也不是可攻击目标。道具与敌人同格合法；道具与建筑同格时，敌人受建筑阻挡，与道具无关。
- 尚未拾取的地面道具不会因超时、离开镜头、波次切换、建筑倒塌或攻击而消失，整局可以返回拾取；落在建筑格时通过高亮图标和G提示保持可见。BUFF拾取后的地面实体移除是正常转化，不属于道具丢失。
- 极端情况下整张地图无合法落点，替换不执行，双方装备保持原状；BOSS掉落保存在待落地队列，有位置后放出，不销毁奖励。

地面主动装备使地图出现可返回的换装点，玩家始终最多携带两件主动装备。被动BUFF拾取后持续积累并独立生效，不能通过换装取回其地面道具。

#### 4.3.7 新增主动装备的使用边界

- **防爆工具箱：** 释放时按建筑格中心距离选定4格内存活建筑和工地，不检查视线；没有目标时不可使用。护盾留在选定对象上，不随玩家移动，也不覆盖后来新建的工地。额度按释放时目标最大生命快照计算，先按护甲结算伤害、再扣护盾、最后扣生命。重复同类护盾取较高剩余额度并刷新持续时间，不相加。升级、坚基光环变化或工地完工不补充护盾数值；目标毁坏即移除。卸下该装备会移除其仍存续的护盾。
- **紧急警报器：** 玩家必须位于已完成建筑格，且4格内至少有一个符合嘲讽条件的敌人。以该建筑作为嘲讽来源，对释放时范围内的合法敌人施加一次效果；不覆盖后来进入范围者。不重置建筑自身技能冷却。沿用嘲讽的通路要求、竞争规则和结束后2秒免疫；BOSS持续时间减半。该建筑毁坏或装备卸下时解除由警报器产生的嘲讽。
- **速凝泡沫罐：** 泡沫固定在释放点，不随玩家移动，不提供伤害、碰撞或视线遮挡。半径内平地生效，采用距离判断，不检查视线，不赋予跨河通行能力。与其他减速取最强值，遵守最低移速限制；BOSS实际减速25%。敌人离开后只移除泡沫减速，其他减速照常存在。持续结束或卸下装备时移除泡沫区。
- **超载发电机：** 启动后随玩家移动的光环只增强已完成建筑，后来进入的建筑也受益。与速射祝福加算，进出范围保留普通攻击周期进度；不加快周期技能。即使启动时没有建筑也允许使用，持续时间照常消耗。
- **应急支撑架：** 仅可作用于玩家当前格内存活、受损、已完成的建筑，不可修工地。实际恢复量=min(当前最大生命×35%, 缺失生命)，费用按第5.2节公式计算；必须足够支付本次实际费用，不能按余额部分修复。满血或费用不足时不触发。抢修扳手不增加本次瞬时恢复量；若当前正在持续修复，瞬时修复后继续原作业，已满血则正常结束。恢复后的生命不会因卸下装备被撤销。
- **动力工作靴：** 最终移速=等级移速×1.6，例如12级约6.246格/秒。保持地形碰撞及正常位移中断作业规则，不能冲过河流或石头，不提供额外无敌；主动换装或持续时间结束后恢复正常速度。

#### 4.3.8 新增被动BUFF的计算与边界

以下效果均只赋予玩家光环覆盖内的已完成建筑；玩家不因此获得直接攻击能力。

- **远望祝福：** 普攻射程=基础普攻射程+BUFF层数×1格，不扩大玩家光环半径、爆炸半径或周期技能目标范围。箭塔等与普攻共用目标的周期技能仍单独按其原始射程选目标；不能借普攻远射程施放越界技能。0攻击建筑不因此获得普攻。
- **破甲祝福：** 总穿甲=min(100%, 技能穿甲+20%×BUFF层数)。例如箭塔穿甲射击与一层破甲祝福合计忽略70%护甲，不减少目标实际护甲属性，不使护甲变负。
- **精准祝福：** 暴击率=min(100%,15%×BUFF层数)，暴击倍率固定1.75，不随层数增加。发射普攻时判定，一发群攻炮弹所有命中目标共用判定。周期技能、余势传递伤害不暴击。
- **坚基祝福：** 最大生命=建筑等级最大生命×(1+25%×BUFF层数)。进入、离开、获得BUFF或升级时保持当前生命比例，不触发修复、治疗和相关统计。例：100/200进入一层光环变为125/250，离开仍为100/200。内部使用浮点比例，避免进出范围的取整获利。工地不生效，完工时先算完工生命比例，再应用光环。
- **共鸣祝福：** 技能冷却=基础技能冷却×[1−min(50%,15%×BUFF层数)]；一层令8秒变为6.8秒。50%为未来同类叠层的建议上限，首版去重掉落最多1层。不缩短控制免疫窗口、技能前摇、效果持续时间或主动装备冷却。进出光环时保留冷却已完成比例，不重置技能、不立即补发技能。
- **猎骑/攻坚祝福：** 分别对带“骑兵”标签或“BOSS”标签的目标生效，普攻与建筑伤害技能均可受益。多个满足条件的专项增伤相加；铁骑统领同时具有骑兵和BOSS标签，两种祝福共同生效为+60%，不相乘。其余普通敌人按兵种表赋标签，其余BOSS仅有BOSS标签。
- **余势祝福：** 只在建筑单体普攻击杀时触发，群攻普攻、周期技能、余势本身不触发。溢出量=max(0,本次对首目标护甲结算后的伤害−命中前剩余生命)。从死亡位置周围2格选最近的另一名存活敌人，距离相同取较早生成者；不需仍在塔射程或玩家光环内，但需死亡位置到接收目标之间不被石头挡住。无人则不触发。转移基础伤害=溢出量×min(100%,50%×层数)，按接收者护甲结算一次，沿用原攻击穿甲；不再叠加攻击、暴击或专项增伤，不连续传递。传递伤害归原塔，击杀正常奖励。
- **伤害顺序：** 等级攻击力 → 攻击光环 → 攻击/技能自身倍率 → 符合目标标签的专项增伤 → 普攻暴击 → 穿甲后的护甲减伤 → 扣血与死亡 → 余势判定。各类百分比在各自类别内部相加，不同类别按上述顺序相乘。
- **伤害快照：** 攻击光环、穿甲、暴击、专项增伤和余势资格/层数在发射时确定；目标护甲与剩余生命在命中时读取。玩家随后移动不改变已发射攻击的进攻属性。

以上层数规则用于后续扩充与调试；当前20项奖励去重掉落不会在同一局重复获得同类BUFF。

## 5. 建造、修复与升级

### 5.1 新建

新建要求：当前格为可建造平地、没有建筑/工地、没有敌人实体重叠、资源足够、类型已解锁、建筑数量未达上限。

确认时一次性扣除完整建造费用，创建工地。费用不会因为离开施工范围重复扣除。

- 工地初始生命为该建筑1级最大生命的30%，施工完成前最大生命也保持该值。
- 工地不能攻击或释放技能。
- 施工完成后，工地剩余生命比例映射为完整建筑生命比例。例如工地剩余50%生命，完工建筑也只有50%生命。
- 受击只扣除生命，不中断作业、不倒扣进度；击退等导致的实际位移会中断作业。
- 玩家离开，进度原样保存，工地继续占格、占建筑名额并可被攻击。
- 工地生命归零后完全销毁，返还建筑名额，不返还建造点和进度。
- 首版不提供拆除退款，避免临时工地反复封路获利；主动拆除可作为后续扩展评估。

### 5.2 工作量与修复公式

每类建筑定义基础工作量W，初始效率且无装备加速时建造时间就是W秒。建造与修复的基础效率维持1:1，临时装备倍率各自独立，详见第4.3.3节。

- 建造时间 = W ÷ 当前建造效率。
- 修复每秒恢复生命 = 当前等级最大生命 × 当前修复效率 ÷ W。
- 从接近空血修至满血的时间约为 W ÷ 当前修复效率，不受建筑等级改变；受击会延长实际完工时间。
- 修复只对已完成建筑有效，工地必须先完成施工。
- 修复费用 = 实际恢复生命 ÷ 当前等级最大生命 × 该类型1级新建费用 × 30%。
- 修复按实际恢复量扣费，内部保留小数；UI资源可显示整数并在费用不足时提示。资源不足以支付下一段修复则停止，不能赊账。
- 同帧结算顺序为伤害/死亡，再结算对仍存活目标的修复；不能把已经摧毁的建筑修回来。

例：箭塔W=3，满血180，建造效率1.0时建造需3秒，修复速度60生命/秒；修复90生命需要1.5秒、6建造点。箭塔虽然修得快，但玩家必须冒险回到它所在格，且持续承受的集火可能超过修复量。

### 5.3 升级

- 升级要求建筑已完成、玩家位于建筑格、角色等级解锁相应建筑等级、资源足够。
- 升级瞬间完成，不需要读条；按键长按不得自动连升。
- 建筑最大生命、攻击和护甲提升，射程与基础攻击间隔保持不变；技能在指定等级发生变化。
- **升级保留生命比例**，避免升级替代修复。100/200生命的建筑升级至300上限后为150/300。
- 升级保留普通攻击与技能冷却的剩余进度，不允许通过升级立刻重置强控。
- 修复中升级，先结算升级，再按新属性继续修复。

## 6. 建筑系统

### 6.1 通用战斗规则

- 建筑自动攻击射程内合法敌人；攻击距离按单位碰撞边缘计算，表内格数为设计标尺。
- 箭塔与寒霜塔需要不被石头遮挡的射线；迫击炮不需要直射视线。
- 普攻与技能分别计时。目标消失则重新选敌，没有合法目标时不浪费普攻。
- 技能冷却结束但没有合法目标时保持就绪，有目标才释放。
- 新建建筑完工后普攻就绪，技能进入完整冷却；技能效果不在施工完成瞬间免费触发。
- 建筑被摧毁，未发射攻击取消；已发射弹道继续结算。
- 单体优先规则：攻击范围内正在威胁玩家的敌人 → 最近敌人 → 距离相同时较早生成者。
- 群攻优先规则：射程内能覆盖最多敌人的落点，数量相同时选最近敌群。

## 7. 敌军决策、寻路与战斗

### 7.1 区分“追击目标”与“当前攻击目标”

没有嘲讽且玩家可被索敌时，敌军的追击目的地是玩家。每个逻辑帧（当前实现每秒30次）按优先级重新检查目标；范围内出现更高优先级的合法目标时立即切换，不等待攻击完成。目标死亡、嘲讽生效/失效、装备无敌开始/结束同样重新判定。寻路计算分帧分批执行。

决策优先级：

1. **有效嘲讽：** 优先攻击/接近嘲讽来源，必要时破障；此时可以放弃可攻击的玩家。
2. **玩家可攻击：** 玩家未处于装备无敌、在当前攻击范围内且满足地形视线条件，优先攻击玩家。
3. **附近建筑可攻击：** 玩家不可攻击时，攻击射程内最近的建筑或工地。
4. **无敌期间无目标：** 玩家处于装备无敌、没有有效嘲讽且攻击范围内没有合法建筑/工地时，原地站立并持续检查，不进入追击与破障。
5. **继续追击：** 玩家可被索敌但没有可攻击对象时，沿通路靠近玩家。
6. **建筑封路：** 有合法追击目标，正常路径不存在但地形路径存在时，选择破障路线，攻击该路线上的第一座阻路建筑。

这里“玩家＞建筑”是对当前可攻击目标的优先级，不代表玩家远在射程外时敌人也无视身边的塔。该定义保留用户规则，并使建筑能够承担拦截作用。

敌人攻击建筑或处于普通攻击前摇、晕眩及技能执行期间，仍持续检查索敌优先级。玩家进入可攻击范围时立即替换普通建筑目标；有效嘲讽仍优先于玩家。同优先级下保留当前合法目标，失效后再选最近建筑。普通攻击前摇中换目标时取消旧攻击，对可攻击的新目标重新完成完整前摇，不通过切换缩短攻击周期。已经发射的箭矢和已锁定位置的范围技能保持原弹道或落点；索敌切换不额外生成攻击，也不解除晕眩。

### 7.2 破障路径

- 先使用把建筑视为障碍的路径搜索，存在路线时按正常路线行走，途中仍执行附近建筑攻击规则。
- 若建筑完全封路，再使用允许穿越建筑格的代价搜索；建筑格代价包含移动代价和预计拆除耗时。
- 预计拆除耗时按该敌人对建筑的有效DPS与建筑当前生命计算；选择总代价较低路线，锁定第一处阻碍。
- 破障目标不存在、被拆除或玩家更换区域时重新规划；不要每帧在相邻两个目标间抖动。
- 石头、河流与边界始终不可破坏、不可通行。禁止将它们作为高代价可穿越格。
- 多个近战单位在目标周围分配可达攻击位置，使用局部避让；位置已满时后续单位排队或绕到其他侧面。
- 敌人之间使用圆形硬碰撞，不允许碰撞体积堆叠；建筑和工地使用与格边界对齐的1×1格方形硬碰撞。敌群接触时相互推挤并形成队列，不产生碰撞伤害。
- 出生时若预定位置与敌人或建筑重叠，在附近寻找最近合法落点；找不到合法落点时不得强行叠放。移动和BOSS冲锋结束后再次解算碰撞，画面帧结束时实体保持分离。
- 大体型单位使用自身半径计算普通寻路与破障寻路，避免选择中心点可达但身体无法通过的路线。玩家与敌人仍使用软推挤，装备无敌期间关闭玩家推挤。
- 地面单位沿共享流场移动，高度不同的相邻格只有在至少一格为坡道时才可连接。普通地面单位不能把高地边缘当作可破坏障碍。
- 空军沿直线空域接近当前目标，无视石头、河流、泥泞、高地边缘和建筑碰撞。空军只与其他空军进行圆形硬碰撞，可以与地面怪物或建筑处于同一水平坐标；所有防御塔仍可正常攻击空军。

### 7.4 伤害与波次成长

- 物理最终伤害 = max(1, 本次攻击经适用增伤与暴击计算后的伤害 × 100 ÷ (100 + 有效护甲))。敌方伤害不获得玩家装备或BUFF增益；建筑伤害详细顺序见第4.3.8节。
- 有效护甲 = max(0, 目标护甲 × (1 − 百分比穿甲))。所有首版伤害均使用此公式。
- 普通敌人生命倍率 = 1 + 0.065 ×（波次 − 1）。
- 普通敌人伤害倍率 = 1 + 0.025 ×（波次 − 1）。
- 普通敌人护甲、移速、奖励不随波次增长；主要通过数量与组成增加压力。
- 第20波普通敌人生命倍率2.235，伤害倍率1.475。
- 属性内部保留小数，UI显示四舍五入；BOSS使用独立固定数值，不再叠乘该公式。

### 8.1 破城先锋：教玩家换位

每8秒以玩家当时位置为中心，标记半径2格区域，预警1.2秒后重砸，造成玩家30、建筑80伤害。标记后不跟随玩家移动，石头不阻挡范围伤害。

### 8.2 猎人工长：压缩施工窗口

每9秒锁定玩家当前位置，预警1.5秒后形成半径2格箭雨区，持续3秒、每秒造成玩家8、建筑12伤害。范围边界持续可见。

### 8.3 铁骑统领：测试阵地通路

每10秒朝玩家当时方向预警1秒，之后沿直线冲锋最多6格，速度8格/秒。撞到第一座建筑时造成100伤害并停止；撞到玩家造成25伤害并击退1格，冲锋结束；撞石头或河流边缘立即停止。每次冲锋只结算一次命中。

### 8.4 围城领主：综合考试

依次循环重砸 → 箭雨 → 冲锋，两次技能启动间至少6秒，不同时发动。生命低于40%后，技能启动间隔变为5秒、移动速度增加15%，不增加控制免疫种类，也不召唤无奖励敌军。

全体BOSS技能施放时暂停自身普攻；预警必须通过形状、动画和声音共同表达，不能只依赖颜色。

### 8.5 BOSS主动装备与BUFF掉落

- 每个BOSS死亡必定额外掉落1个奖励道具，可能为主动装备或被动BUFF道具，普通敌人不掉此类道具；不替代原有建造点和经验奖励。数量与抽取方式为首版建议。
- 从第4.3.2节9种主动装备和11种BUFF道具、共20项奖励中按单项等概率抽取，并在本局掉落池中暂时移除已掉落类型，首版4次BOSS不会重复掉落同名奖励。首次抽取主动总概率45%、BUFF总概率55%；后续按剩余项计算，不是先对两类各取50%。双同名主动与BUFF叠层仍按通用规则实现，便于以后扩充掉落配置。
- 第5、10、15、20波BOSS各提供一次掉落。只有玩家已携带两件主动装备、再拾取第三件主动装备时才需要替换；拾取BUFF永远不会占用主动格或触发替换，因此不再保证第15波出现替换。
- 第20波掉落先于胜利检查处理；如果仍有残余敌人，玩家可拾取使用。如果已满足胜利条件则直接结算，不为拾取奖励强行延长战斗。
- 终局主动或BUFF掉落目前仅能帮助清场，没有局外继承价值。在混合去重掉落池下，部分对局可能始终不需要更换主动装备；首版接受该结果。是否增加中途掉落、主动保底或单BOSS多件奖励，待测试后决定，不在本次规则调整中额外增加。
- 每个BOSS只结算一次掉落，落点与顺延遵守第4.3.6节。
- 本次仅扩充内容池，仍保持4次BOSS各掉1项；单局最多获得4项奖励，20项用于跨局变化，不保证每件都在同局出现。测试模式应提供指定掉落与直接授予功能，覆盖全部新内容。

## 9. 建造点与角色成长

- 每提升一级，基础建造效率相对初始值增加5%；等级L基础效率 = 1 + 0.05 × (L−1)。基础修复效率与其相同，主动装备倍率独立计算。
- 无装备加速时，12级移速3.904格/秒，建造效率1.55；箭塔施工约1.94秒，满血工作量的修复约1.94秒。
- 升级不暂停战斗，显示简短提示；初版采用固定解锁，暂不加入随机三选一，以便先验证施工生存循环。
- 当前建筑数包括所有完工建筑和未完工工地；被毁立即释放名额。

### 9.3 经济校准方法

按第10节波次表逐项核算完整击杀收入，并比较以下典型支出：

- 1座4级箭塔累计费用：40 + 32 + 48 + 72 = 192。
- 1座4级迫击炮累计费用：75 + 60 + 90 + 135 = 360。
- 1座4级寒霜塔累计费用：65 + 52 + 78 + 117 = 312。
- 1座4级嘲讽塔累计费用：60 + 48 + 72 + 108 = 288。
- 1座4级拒马累计费用：20 + 16 + 24 + 36 = 96。

满编与满级不是默认一定达到的目标。测试中应区分资源富余是因为收入过高、缺乏可施工位置、上限过紧，还是玩家不知道如何升级；不能只通过降低收入解决所有问题。

## 11. HUD、反馈与信息

### 11.1 常驻显示

- 顶部：生命、等级与经验条、建造点、当前波次/20、下一波倒计时。
- 底部：五类建筑按钮，显示费用、解锁等级和快捷键；未解锁建筑可查看能力但不能建造。
- 玩家附近：当前作业进度、预计剩余时间；移动后工地继续显示暂停进度。
- 玩家站在建筑格时：建筑等级、生命、升级费用、修复操作与预计费用。
- 建筑数量显示“当前/上限”，达到上限时建造按钮给出原因。
- 镜头边缘：来敌方向和BOSS位置；小地图显示地形、玩家与己方建筑。
- 双主动装备格：装备图标、Q/空格快捷键、冷却与效果剩余时间，仅显示主动装备。
- 独立被动BUFF栏：显示已获得BUFF图标、层数与累计数值，查看详情时显示光环范围及当前覆盖建筑数；不占主动槽，也不提供替换按钮。
- 地面道具：区分主动装备与BUFF的类型图标、名称和拾取提示，小地图保留位置标记；只有主动装备满格拾取才展示三件主动装备对比与两个替换按钮。

### 11.2 关键反馈

- 可建造格显示轮廓；禁止建造时给出唯一主要原因，例如“河流不可建造”“敌人占据此处”“建造点不足”。
- 工地采用脚手架与未完成结构，完工建筑有明显形态区别。
- 嘲讽出现敌人转向提示和来源标记；减速、眩晕用不同图标和动作表现。
- 受击采用短促反馈，不用强烈镜头抖动干扰施工判断。
- 暂停施工不使用“失败”音效，因为中断是正常策略。
- 被摧毁建筑显示位置警告，首版不弹出阻挡视野的确认框。
- BOSS预警必须先于伤害出现，并保持实际范围与显示范围一致。
- 装备无敌用独立轮廓和剩余秒数表达，区别于0.3秒受击闪烁；暂停追击的敌人保留待机动作，避免被误认为卡死。
- 被动BUFF选中查看时显示随玩家移动的光环边界，受益建筑显示对应小图标；不持续绘制高亮大圆遮住地面预警。拾取时提示“获得BUFF”，不出现“已装备”反馈。
- 建筑护盾以独立条显示，泡沫使用固定地面纹理；紧急警报器标出作为嘲讽来源的建筑。应急支撑架使用前显示实际修复量和费用，不满足条件时提示原因。

## 12. 典型游玩片段

**开局：** 玩家在起始箭塔附近建第二座箭塔，沿两塔外侧走位，让单方向步兵进入火力圈。第一次离开工地躲攻击，再回来续建，理解进度保存。

**中期：** 重装兵停在拒马前，迫击炮清理后排；玩家准备修复拒马时被弓箭手瞄准，先横移躲箭，再回格修复。骑兵绕过石群追来，寒霜塔脉冲制造施工窗口。

**后期：** 嘲讽塔暂时吸引集火，玩家趁机升级输出塔。BOSS重砸锁定玩家脚下，玩家退出主阵地，把敌群带向备用火力点；主阵地被砸坏后，需要决定是否冒险回去修复。

**装备与成长：** 玩家在主动格已满时拾取火力祝福，立即获得攻击光环，两件主动装备保持原样。若之后再掉落庇护安全帽，而玩家携带疾建手套与抢修扳手，则必须选择一件主动装备落地替换。换装不影响已获得的火力BUFF；旧主动装备以后仍可拾回。此片段说明交互规则，不代表每局都有固定掉落顺序。

## 13. 主要风险与调参方向

| 风险 | 观察信号 | 优先调整 |
|---|---|---|
| 永久绕圈、几乎不施工 | 玩家停止建设仍能长期安全拖延 | 检查骑兵与弓箭手压力、胜利清场条件；保留可规避窗口 |
| 一直站在同一格修塔 | 大部分时间只按修复即可过关 | 检查远程和BOSS威胁、修复费用；保留与建造相同的基础效率 |
| 塔墙令寻路失效 | 敌人停在建筑外，不攻击也不绕路 | 修复破障路径与攻击位分配，不能靠穿墙补救 |
| 敌人全被外围建筑拖住 | 玩家很少受到直接追击 | 调整出生方向、远程和骑兵比例；不要暗改已约定攻击优先级 |
| 控制塔无限接力 | 大群敌人长期无法行动 | 检查控制免疫窗口及减速取强规则 |
| 后期只剩满屏图标 | 无法看清玩家、箭矢和预警 | 精简受击数字、降低同类特效密度，保持危险技能清晰 |
| 早期损失后无法翻盘 | 第2～4波失去输出后无资源重建 | 先调整初始资源、前期敌群与施工时间；是否增加应急手段另行决定 |
| 满级满编后资源失去意义 | 终局长期大量积存建造点 | 先核算经济，再调整建筑上限/价格/维护消耗，不直接加无意义资源坑 |
| 无敌停怪过于强势 | 无敌期间远处敌人被火力单方面消灭，成为必选装备 | 先调持续时间与冷却，保留用户指定的不可索敌、无目标停步规则 |
| 换装绕过冷却 | 落地拾回后可反复触发主动 | 检查实例冷却与同类共享冷却，不销毁替换道具 |
| 主动装备选择过少 | 混合掉落后部分对局不足3件主动装备，整局不发生替换 | 记录主动/BUFF分布与使用体验，必要时另议掉落数量或保底 |
| 同名光环或进出范围产生额外攻击 | 攻速异常或伤害无限放大 | 检查加成求和、普攻周期比例和弹道伤害快照 |

## 14. 原型范围与实现边界

### 14.1 完整玩法原型包含

- 1张固定地图、四类基础地形、高低地与坡道寻路验证。
- 玩家移动、生命、成长、原地建造/修复/升级。
- 5类建筑、4个等级、各自周期技能。
- 4类普通敌人、4次BOSS战、完整20波。
- 双主动装备格、9种主动装备、11种被动BUFF、BOSS混合掉落、主动拾取替换与地面保存、BUFF拾取转化、无敌索敌分支、护盾、地面泡沫、移动光环与伤害触发效果。
- 碰撞、直射视线、破障寻路、控制抗性、暂停与结算。
- HUD、建筑状态、出生预警、BOSS预警与必要音效。

暂不包含多人、联网、局外成长、装备品质/强化、随机三选一、随机地图、剧情、付费或排行榜。后续是否加入应由原型结果决定。

### 14.2 制作顺序

1. **基础验证：** 平地+石头、玩家移动、步兵、箭塔、建造/修复、目标优先级与封路破障。
2. **策略验证：** 河流、全部普通敌人、拒马/迫击炮/寒霜/嘲讽、升级成长，先跑前10波。
3. **完整节奏：** 4次BOSS战、双主动装备与被动BUFF、完整20波、HUD、结算、难度与经济调优；重点验证无敌索敌、落地换装与BUFF独立积累。

若采用网页原型，建议2D Phaser + TypeScript。战斗规则和数据配置独立于画面，使用DOM呈现HUD与菜单。程序内部区分单位状态、目标选择、路径、作业进度、波次调度和奖励结算；美术首轮使用形状清楚的占位图，玩法通过后再替换正式素材。

## 15. 首轮验收与测试标准

### 15.1 规则验收

1. 施工至40%后移动，回来继续，进度和费用都不重置。
2. 施工中受普通伤害不打断；被击退产生位移时停止。
3. 受损工地完成后保持相同生命比例；工地毁坏后不能继续。
4. 建筑受损时升级保留生命比例与技能冷却，升级瞬间完成。
5. 无装备加速时，修复整条生命所需工作时间与该类型建造相同；建造/修复装备只分别改变对应速度，按实际修复量扣费。
6. 玩家与建筑都可攻击时，普通敌人选择玩家；玩家不可攻击时能攻击建筑；嘲讽可覆盖普通优先级。
7. 玩家站在建筑格中仍可被近战和远程命中，不能借碰撞获得免疫。
8. 建筑完全封路后敌人开始破障；石头和河流不会被当成可穿越格。
9. 弓箭被石头阻挡、能够飞过河流；迫击炮可越过石头但不能自动追踪落点。
10. 存活旧敌人不阻止下一波启动；第20波未生成完或仍有敌人时不结算胜利。
11. 击杀奖励只结算一次；暂停不推进作业、技能、波次或伤害计时。
12. 多控制塔不造成永久眩晕或无限嘲讽，BOSS抗性与说明一致。
13. 主动装备最多携带两件；空格拾取正确入槽，满格取消不改变装备。被动BUFF不占格，不能加入主动槽。
14. 替换后旧装备出现在玩家地图格；该格有其他道具时逐圈顺延，跳过非法地形；多次替换不丢失或复制实例。
15. 地面道具不阻挡怪物、弹道、建造，不被攻击或波次切换清除；可以与建筑共格并正常拾取。
16. 主动装备落地拾回、换槽、换成同类实例均不能绕过冷却；卸下立即终止效果，暂停冻结所有装备计时。
17. 装备无敌即时移除玩家索敌资格：范围内有建筑则打建筑，无目标则站立；有效嘲讽仍生效；结束后恢复追击。
18. 普通受击保护不触发停怪；无敌期新工地可被攻击，玩家不受伤或击退；BOSS预警取消与已释放技能按规则区分。
19. 光环随玩家移动，范围边界、BUFF获得和同类叠层正确；替换主动不移除BUFF，进出范围不重置普攻，攻速不加快技能冷却。
20. 每个BOSS只掉一件；装备掉落不替代自动资源奖励；第20波掉落不会阻碍正常胜利结算。
21. 主动格满时仍可拾取BUFF，地面实体消失并直接增加玩家BUFF，不弹替换、不让任何主动装备落地；重复输入不重复增加BUFF。
22. 已拾取BUFF跨波次保留、不因主动换装或无敌而消失，本局结束清除；未拾取BUFF道具仍按地面保存、无碰撞及顺延规则处理。
23. 防爆工具箱能保护工地，护盾不相加；升级或坚基光环变化不补盾，卸下清理正确。
24. 紧急警报器只以当前格已完成建筑为来源，遵守嘲讽抗性与免疫，不重置建筑技能；泡沫不阻路，离开区域后只移除对应减速。
25. 超载与速射按加算得到正确普攻间隔，不加快技能；动力工作靴不能穿越地形，位移仍中断作业。
26. 应急支撑架仅修复实际缺血并按实际量扣费，费用不足/满血/工地均不触发；抢修扳手不放大瞬时恢复量。
27. 坚基光环进出及升级保持血量比例，不能反复走位回血；共鸣光环进出保持技能冷却进度，不能刷新技能。
28. 远望不扩大周期技能范围；精准仅对普攻判定且群攻结果一致；破甲与技能穿甲加算并封顶。
29. 骑兵与BOSS标签正确，铁骑统领双专项增伤为+60%；余势仅单体普攻击杀触发、不递归、不重复增伤，转移击杀奖励只结算一次。
30. 地面单位不能直接跨越高地边缘，并能从任一坡道进出全部平台；大体型敌军也不会卡在坡道口。
31. 空军可越过高地边缘、石头、河流、泥泞和建筑；空军只与空军硬碰撞，仍执行嘲讽＞玩家＞建筑的实时攻击优先级。
30. 配置表包含9件主动、11种BUFF；通过指定掉落验证所有20项，不依赖随机单局碰巧覆盖。

### 15.2 体验验证

找5～8名首次体验者，记录而不是预设已经达标：

- 前2分钟能否理解“必须到现场施工”和“移动会保留进度”。
- 能否说明新建、升级、修复各自至少一个合适时机。
- 第7波骑兵出现时是否有应对手段，而不是无提示地必死。
- 每次死亡能否辨认主要原因，尤其是弓箭瞄准、BOSS范围及受击后的撤退路线。
- 通过者战斗时长是否大致处于14.5～17分钟；持续超出需检查清场效率和BOSS血量。
- 是否出现一套建筑组合明显排斥所有其他组合；是否必须在同一位置长时间按修复。
- 是否理解“无敌只保护玩家、建筑仍会挨打”；能否辨认地面装备可以返回拾取，以及替换不会销毁旧装备。
- 当第三件主动装备出现时，替换是否形成有效取舍；BUFF拾取与主动换装是否容易区分，被动成长能否被感知。

建议埋点：波次启动/清空、玩家坐标与受击来源、新建/完工/中断/摧毁、修复生命和费用、升级、每类建筑伤害与控制次数、每波末资源和存活敌人数、主动装备掉落/拾取/替换/使用、BUFF掉落/拾取/层数变化、光环覆盖时长、无敌期间敌人停步时长与建筑损失。

### 15.3 性能与稳定性

网页原型以明确记录的测试电脑和浏览器为基准，常规战斗目标60 FPS；设置400个活动敌人、16座建筑的压力场景，检查寻路、范围技能和目标扫描耗时。该数值是测试负载，不是游戏内刷怪上限。

若出现敌人积压，不能静默删怪或跳过应生成单位。先优化寻路复用、空间索引和批量更新，再调整实际难度配置。发布前至少完整完成一次胜利流程和一次死亡重开流程。

## 16. 本版需通过试玩确认的设计判断

- 玩家可进入己方建筑格、敌人不能进入，是“原地操作”与“塔防阻路”之间的规则选择，应优先验证表现是否自然。
- 受击无敌0.3秒、无主动攻击、自动获取资源、无拆除退款，均为新增建议。
- v0.3“两件主动装备上限、主动替换落地、被动拾取转为玩家BUFF且不占格”为用户确定规则；主动装备与BUFF的名称、数值、冷却、光环半径、BUFF持续至本局结束及同类叠层、每BOSS一个奖励的混合去重掉落，以及无敌时将“范围”解释为攻击范围，均为本文补充建议。
- v0.4已按用户选择纳入全部A1～A6与P1～P8，保留原有3件主动和3种BUFF。新增内容的初值、同类叠层上限、标签与溢出伤害结算细则需在指定测试场景中验证，不能以随机四次掉落代替全内容验收。
- 固定成长保留生存与建造的清晰主线，但局内随机性较弱；若核心循环成立，再考虑围绕建筑技能的三选一成长。
- 20波采用固定45秒启动间隔，保证可控节奏，同时允许战斗积压；若需要严格15分钟结束，必须另行变更胜负与终局规则。
- 全部数值是首轮测试起点，文档完整不代表平衡已验证。首先验证“敌人追击下是否有可读、可争取的施工窗口”，再细调伤害和经济。

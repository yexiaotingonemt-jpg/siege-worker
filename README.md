# 围城工匠 · The Last Builder

可试玩的1～3人跨设备联机/本机同屏俯视角生存建造游戏。依据《完整玩法策划案 v0.13》与《角色与建筑属性补充设计 v0.9》实现，使用 Phaser 3 + TypeScript + Vite；Cloudflare Durable Objects 提供实时房间。

在线试玩：https://yexiaotingonemt-jpg.github.io/siege-worker/

实时服务器：https://siege-worker-realtime.yexiaoting-onemt.workers.dev/health

## 运行

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5186/ 。构建发布文件使用 `npm run build`，生成 `dist/`；`npm run preview` 可本地预览构建结果。也可以双击本目录的 `启动游戏.cmd`。程序使用本地生成的矢量绘制与合成音效，不依赖运行时图片、字体或音频外链。

## 玩法与操作

- 跨设备联机：每台设备设置自己的账号昵称。房主选择“跨设备联机→创建新房间”，队友在其他设备输入HUD显示的6位房间码加入。
- 网络模式每台设备都用WASD移动、数字1～5选塔、E/R/F/G操作、Q/空格使用主动；每个账号只控制自己的佣工。
- 队伍共享等级、建造点、建筑、两格主动装备和BUFF；每人拥有独立生命、位置、选塔与施工任务，全队阵亡才失败。
- P2/P3实时加入会在2秒预警后补齐当前波敌军，并提高、提前未来波次。队友断线后佣工留在原地且难度不降低；房主断线则房间结束。
- 本机同屏仍可在开局选择1～3名佣工，使用以下三套键位：
- P1：WASD移动，数字1～5选塔，E/R/F/G操作，Q/空格使用主动。
- P2：方向键移动，[ / ]选塔，回车/斜杠/句号/逗号操作，分号/引号使用主动。
- P3：IJKL移动，N/M选塔，O/U/Y/H操作，V/B使用主动。
- 站在建筑格上，R持续修复，F瞬间升级。移动中断作业，进度保留；普通受伤不取消施工。
- G拾取脚下道具；Q和空格使用两个主动槽。满格拾取主动时选择替换，旧装备留在原格；冷却不会因换装重置。
- 被动奖励拾取后直接挂在玩家身上，持续整局、不占主动槽，建筑在玩家5格范围内受益。
- 本机模式按P暂停，Esc取消作业/替换或打开暂停；联机模式只有房主可用HUD暂停，队友打开手册不暂停战斗。
- 手机上使用左侧摇杆移动，点击建筑卡片、上下文操作及装备按钮。

10秒准备后按人数动态生成波次：1人每45秒、普通敌军1.0倍；2人每42秒、1.55倍；3人每39秒、2.1倍。实时加入会补齐当前波的新旧倍率差额，重算未来未触发波次并压缩剩余等待；佣工阵亡不会降难度。上一波没打完，新一波仍会出现。5/10/15/20波有BOSS。全部计划敌人生成并被消灭后胜利，全队生命归零失败。

## 实现内容

- 64×64固定地图：断续石脊、河流、水洼、减速泥地和4块高地平台形成多条进攻通道；高地边缘使用一格宽断崖面，地面单位只能经渐变坡面切换高度。
- 五类建筑、四级属性、周期技能、进度保留工地、比例修复和升级。
- 五类普通敌军、四名BOSS；第6波起出现可越过所有地面限制的飞翼掠夺者，另有近战前摇与挥空、弓箭弹道、重砸/箭雨/冲锋预警。
- 玩家优先的攻击决策：怪物出生时追击最近佣工，范围内出现更近的玩家目标会即时重锁；另有嘲讽覆盖、建筑阻挡与按体型计算的加权破障路径。
- 地面敌军使用圆形实体碰撞，建筑与工地使用1×1格方形碰撞；空军使用独立高度碰撞层，只与空军互相推挤。
- 全部9件主动装备和11种被动BUFF，包括护盾、泡沫、瞬时修复、暴击、穿甲、标签增伤、溢出伤害。
- BOSS混合去重掉落，地面道具逐圈顺延、无碰撞；同类型主动共享冷却，地面实例继续冷却。
- 装备无敌移除索敌资格；敌人攻击范围内有建筑就攻击，否则站立，有效嘲讽仍可引导它们。
- 中文战地手册、三人队伍血条与编号、多人自适应镜头、属性提示、敌军/BOSS显示、小地图、暂停、死亡/胜利结算、合成音效、单人手机操作。
- 跨设备实时房间：独立浏览器账号ID与昵称、6位房间码、3账号占位；P2/P3只预测本机佣工，战场实体使用轻量插值，不重复运行完整战斗AI；房主权威快照纠偏，服务端校验协议与消息频率。
- 独立“自由演练”：玩家不受伤、全建筑解锁、额外资源；通过手册投放全部20种奖励，底部按钮可推进下一批。演练的伤害保护不移除索敌资格，方便检查敌军行为；安全帽仍按正常装备规则移除索敌。

## 尚未定稿规则的实现选择

- 完整修复耗时为新建的2倍，修满费用为1级建造费用的50%；抢修扳手使修复速度翻倍。建造与修复主动仍只作用于各自操作。
- 使用当前有效最大生命（含坚基BUFF）计算修复比例与费用；应急支撑架为主动装备的收费例外。
- 出生点失效时保留该批次、选择合法区域并重新给予2秒预警；后续波次正常计时，不跳过敌人。
- 怪物成长在出生时绑定所属波次；旧敌人不会在新波开始时突然增加属性。
- 保留主案0.3秒普通受击保护，也保留“低伤害保护可能免疫随后BOSS伤害”的现有规则。安全帽完整免疫所有敌方伤害。
- 没有擅自增加免费重建或拆除。若全部输出被毁且资源不足，需要选择重开；旧建筑/工地仍占名额。
- BOSS施放距离采用属性补充中的8/10/6格，首次等待4/5/4秒，最终BOSS按循环调度。BOSS可同时留场。
- 工地护甲0，建筑和工地使用1格方形碰撞；普通敌军与BOSS使用各自的圆形碰撞半径。高地边缘不提供射线遮挡，坡道是地面单位唯一的高度切换入口。

## 验证

```sh
npm test
npm run build
node scripts/browser-qa.mjs
node scripts/online-qa.mjs
npm run worker:check
```

浏览器检查需要先运行开发服务，并需要可用的Chrome。截图和浏览器报告输出到 `qa/`。

规则测试覆盖实时加入、当前波增援、未来波次重算、多人压力缩放、最近玩家索敌、同时施工、全队失败条件、建造中断与恢复、实际修复费用、比例升级、BUFF与双主动槽、无敌索敌、控制抗性、挥空、余势、BOSS预警、定时刷波、高低地、坡道、空地碰撞分层、出生失败保留、暂停、死亡与胜利等。跨设备QA使用三个隔离浏览器账号验证房间加入、80毫秒内P2/P3本地预测、权威位置收敛、远程建造、资源扣除、动态增压、非法输入拒绝和错误房间拒绝。

长局测试使用满级预置阵地和测试专用维护，运行完整20波并清除928名敌人；它验证完整战斗流程，不代表普通模式平衡已验证。另有928名敌人同时存在的压力场景，验证未丢波、没有无效坐标。

目前是功能完整的可玩原型，使用程序化美术与合成音效。网络账号是保存在浏览器中的唯一ID与昵称，没有密码登录、账号找回、房主迁移或中途存档；房主设备负责权威战斗模拟。正常难度、网络延迟、断线体验、奖励强度和长时间手机性能仍需要真实设备多轮试玩。

## 文件结构

- `src/data.ts`：建筑、敌人、20波及全部奖励配置。
- `src/map.ts`：地形、高度层、坡道、碰撞、视线和共享流场寻路。
- `src/sim.ts`：独立战斗模拟、资源、操作、成长和装备系统。
- `src/network.ts` / `src/protocol.ts`：浏览器账号、WebSocket房间协议、本地预测指标与服务端共享校验规则。
- `src/render.ts`：Phaser战场与矢量图形。
- `worker/index.ts` / `wrangler.jsonc`：Cloudflare Durable Object房间服务器与部署配置。
- `src/main.ts` / `src/style.css`：中文HUD、菜单、触屏操作。
- `tests/`：规则与长局测试；`scripts/browser-qa.mjs`与`scripts/online-qa.mjs`：本机及跨设备浏览器交互与截图。

普通页面只暴露只读状态快照。显式加入 `?qa` 时开放测试场景控制，供自动化使用；线上对局没有排行榜或竞争性结果。

# 围城工匠 · The Last Builder

可试玩的1～3人跨设备联机/本机同屏俯视角生存建造游戏。依据《完整玩法策划案 v0.28》与《角色与建筑属性补充设计 v0.23》实现，使用 Phaser 3 + TypeScript + Vite；Cloudflare Durable Objects 提供实时房间。

在线试玩：https://yexiaotingonemt-jpg.github.io/siege-worker/

实时服务器：https://siege-worker-realtime.yexiaoting-onemt.workers.dev/health

## 运行

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5186/ 。构建发布文件使用 `npm run build`，生成 `dist/`；`npm run preview` 可本地预览构建结果。也可以双击本目录的 `启动游戏.cmd`。程序使用本地生成的矢量绘制与合成音效，不依赖运行时图片、字体或音频外链。

## 玩法与操作

- 跨设备联机：每台设备设置自己的账号昵称。房主选择“跨设备联机→创建新房间”，队友在其他设备输入HUD显示的6位房间码加入。
- 网络模式每台设备都可用WASD或鼠标右键移动、数字1～5选塔、E/R/F/G指定操作、空格或鼠标左键智能建造/续建/修理、Q/X使用主动；每个账号只控制自己的佣工。
- 队伍共享唯一的等级、经验、建造点、建筑、两格主动装备和BUFF；任意佣工或己方建筑击杀都会让所有成员同步获得经验和等级，每人拥有独立生命、位置、选塔与施工任务。建造点不会随时间恢复，新玩家加入也不会增加资源。
- P2/P3实时加入会在2秒预警后补齐当前波敌军，并提高、提前未来波次。队友断线后佣工留在原地且难度不降低；房主断线则房间结束。
- 本机同屏仍可在开局选择1～3名佣工，使用以下三套键位：
- P1：WASD或鼠标右键移动，数字1～5选塔，E/R/F/G操作，空格或鼠标左键智能建造/修理，Q/X使用主动。
- P2：方向键移动，[ / ]选塔，回车/斜杠/句号/逗号操作，分号/引号使用主动。
- P3：IJKL移动，N/M选塔，O/U/Y/H操作，V/B使用主动。
- 站在建筑格上，R持续修复，F瞬间升级。玩家可以修复任意己方建筑，费用从队伍资源池扣除。敌人锁定玩家并进入攻击距离，或已有敌方弹道飞来时，持续维修速度降低50%，但任务不会中断；移动中断作业，进度保留。
- 队伍以120共享建造点和0座建筑进入10秒准备阶段，自行建造第一座箭塔或拒马。场上建筑总数不设玩法上限。
- 存活玩家靠近阵亡队友可支付80队伍建造点复活对方；目标恢复50%生命并获得1秒受击保护。全队同时阵亡才失败。
- G拾取脚下道具；Q和X使用两个主动槽。满格拾取主动时选择替换，旧装备留在原格；冷却不会因换装重置。
- 被动奖励拾取后直接挂在玩家身上，持续整局、不占主动槽，建筑在玩家5格范围内受益。
- 本机模式按P暂停，Esc取消作业/替换或打开暂停；联机模式只有房主可用HUD暂停，队友打开手册不暂停战斗。
- 手机上使用左侧摇杆移动，点击建筑卡片、上下文操作及装备按钮。

10秒准备后按人数动态生成波次：1人每45秒、普通敌军1.00倍；2人每42秒、1.55倍；3人每39秒、2.10倍。每个主波会继续拆分为多批敌军：第1～5波各4批，第6～21波各6批，批次间隔3秒。建造点只来自初始资源和击杀奖励，不会随时间恢复。实时加入会补齐当前波的新旧人数倍率差额，重算未来未触发波次并压缩剩余等待；佣工阵亡或断线不会降低难度。上一波没打完，新一波仍会出现。第3/6/9/12/15/18/21波各有一只BOSS，第21波由终局大BOSS“城塞巨像”带领护卫进攻；BOSS必掉奖励，普通小怪死亡时有0.5%概率掉落主动装备或被动BUFF。全部计划敌人生成并被消灭后胜利，全队生命归零失败。

## 实现内容

- 32×32固定地图：中心营地、断续石脊、河流、水洼、减速泥地和4块高地平台；严格使用确认稿同源的草甸、泥地、河水、岩石与崖壁材质，河岸和覆草岩壁按相邻格连续拼接，地面单位只能经跨两格木制缓坡切换高度。
- 五类建筑、四级属性、周期技能、进度保留工地、跨玩家维修、比例修复和升级；迫击炮每发按等级最多命中8/10/12/15个爆炸范围内目标；建筑记录建造者，所有塔的击杀建造点进入队伍资源池。
- 五类普通敌军、五种BOSS共7次登场；第6波起出现可越过所有地面限制的飞翼掠夺者，另有近战前摇与挥空、弓箭弹道、重砸/箭雨/冲锋预警。
- 玩家优先的攻击决策：怪物出生时追击最近佣工，范围内出现更近的玩家目标会即时重锁；另有嘲讽覆盖、建筑阻挡与按体型计算的加权破障路径。
- 地面敌军使用圆形实体碰撞，建筑与工地使用1×1格方形碰撞；空军使用独立高度碰撞层，只与空军互相推挤。
- 全部9件主动装备和11种被动BUFF，包括护盾、泡沫、瞬时修复、暴击、穿甲、标签增伤、溢出伤害。
- BOSS必定从混合去重奖励池掉落一件，普通小怪每次死亡独立进行0.5%掉落判定；地面道具逐圈顺延、无碰撞，同类型主动共享冷却，地面实例继续冷却。
- 装备无敌移除索敌资格；敌人攻击范围内有建筑就攻击，否则站立，有效嘲讽仍可引导它们。
- 使用确认后的中世纪透明像素动画：P1石匠、P2木匠、P3铁匠各有四向移动、建造和修复动画；步兵、重装、弓手、骑兵、空军和BOSS各有四向移动与六帧攻击动画。9张图集替代132个独立请求，另有中文战地手册、多人自适应镜头、小地图、结算、合成音效和手机操作。
- 跨设备实时房间：独立浏览器账号ID与昵称、6位房间码、3账号占位；P2/P3只预测本机佣工，战场实体使用轻量插值，不重复运行完整战斗AI；房主权威快照纠偏，服务端校验队伍资源、建筑归属、协议与消息频率。
- 独立“自由演练”：玩家不受伤、全建筑解锁、额外资源；通过手册投放全部20种奖励，底部按钮可推进下一批。演练的伤害保护不移除索敌资格，方便检查敌军行为；安全帽仍按正常装备规则移除索敌。

## 尚未定稿规则的实现选择

- 完整修复基础耗时为新建的2倍，修满费用为1级建造费用的50%；抢修扳手使修复速度翻倍。处于受攻击状态时，持续维修速度再乘50%；应急支撑架的瞬时修复不受影响。
- 使用当前有效最大生命（含坚基BUFF）计算修复比例与费用；应急支撑架为主动装备的收费例外。
- 出生点失效时保留该批次、选择合法区域并重新给予2秒预警；后续波次正常计时，不跳过敌人。
- 怪物成长在出生时绑定所属波次；旧敌人不会在新波开始时突然增加属性。
- 保留主案0.3秒普通受击保护，也保留“低伤害保护可能免疫随后BOSS伤害”的现有规则。安全帽完整免疫所有敌方伤害。
- 没有擅自增加免费重建或拆除。若全部输出被毁且队伍资源不足，需要依靠现存建筑击杀获得资源，否则只能选择重开；旧建筑/工地仍占据地图格。
- BOSS施放距离采用属性补充中的8/10/6格，首次等待4/5/4秒，最终BOSS按循环调度。BOSS可同时留场。
- 工地护甲0，建筑和工地使用1格方形碰撞；普通敌军与BOSS使用各自的圆形碰撞半径。高地边缘不提供射线遮挡，坡道是地面单位唯一的高度切换入口。

## 验证

```sh
npm test
npm run build
node scripts/browser-qa.mjs
node scripts/online-qa.mjs
npm run worker:check
```

浏览器检查需要先运行开发服务，并需要可用的Chrome。截图和浏览器报告输出到 `qa/`。

规则测试覆盖共享队伍资源、无时间回复、多人同时消费、跨玩家维修、付费复活、共享击杀收益、无限建筑、智能操作、实时加入、当前波增援、多人压力缩放、最近玩家索敌、全队失败、比例升级、BUFF与双主动槽、无敌索敌、定时刷波、高低地、坡道、碰撞分层、暂停及胜负。跨设备QA使用三个隔离浏览器账号验证P2/P3本地预测、权威位置收敛、空格远程建造、共享资源扣除、跨设备复活、动态增压、非法输入和错误房间拒绝。

长局测试使用满级预置阵地和测试专用维护，在32×32地图运行完整21波并清除977名敌人；它验证完整战斗流程，不代表普通模式平衡已验证。另有977名敌人同时存在的压力场景，验证未丢波、没有无效坐标或碰撞重叠。

目前是功能完整的可玩原型。角色和敌军直接使用确认视觉稿提取的透明像素素材，地图使用从确认示意图建立的六类手绘材质图集、连续河岸、覆草崖壁和双格木制缓坡；视觉方向稿和透明源表保存在 `docs/concepts/`。网络账号是保存在浏览器中的唯一ID与昵称，没有密码登录、账号找回、房主迁移或中途存档；房主设备负责权威战斗模拟。正常难度、网络延迟、断线体验、奖励强度和长时间手机性能仍需要真实设备多轮试玩。

## 文件结构

- `src/data.ts`：建筑、敌人、21波及全部奖励配置。
- `src/map.ts`：地形、高度层、坡道、碰撞、视线和共享流场寻路。
- `src/sim.ts`：独立战斗模拟、资源、操作、成长和装备系统。
- `src/network.ts` / `src/protocol.ts`：浏览器账号、WebSocket房间协议、本地预测指标与服务端共享校验规则。
- `src/render.ts` / `src/facing.ts`：Phaser战场、地形绘制、佣工作业动画、敌军四向移动与攻击时间轴、透明角色素材池及Y轴深度排序；`public/assets/characters/animated/`保存9张实机动画图集。
- `worker/index.ts` / `wrangler.jsonc`：Cloudflare Durable Object房间服务器与部署配置。
- `src/main.ts` / `src/style.css`：中文HUD、菜单、触屏操作。
- `tests/`：规则与长局测试；`scripts/browser-qa.mjs`与`scripts/online-qa.mjs`：本机及跨设备浏览器交互与截图。

普通页面只暴露只读状态快照。显式加入 `?qa` 时开放测试场景控制，供自动化使用；线上对局没有排行榜或竞争性结果。
